# SynthData

Precision Synthetic Data Generation Platform

SynthData is a modern, privacy-first synthetic data generation platform built for developers, QA teams, analysts, and machine learning workflows.
Generate realistic fake datasets instantly inside your browser without exposing real user information.

The platform is designed with a clean Swiss-inspired interface, production-grade responsiveness, and a fully client-side architecture for maximum speed and privacy.

---

# Features

* Dynamic schema builder
* Realistic synthetic data generation
* CSV export support
* JSON export support
* Local-only processing
* No login or authentication required
* Responsive dashboard experience
* Modern SaaS-grade UI
* Keyboard accessible interactions
* Mobile-friendly layouts
* Fast client-side generation engine

---

# Privacy First

All dataset generation happens entirely inside the browser.

SynthData:

* does not store user data
* does not require accounts
* does not use cloud processing
* does not upload datasets

Your generated data never leaves your device.

# Installation

Clone the repository:

```bash
git clone https://github.com/your-username/synthdata.git
```

Navigate into the project:

```bash
cd synthdata
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open:

```bash
http://localhost:3000
```

---

# Production Build

Build the application:

```bash
npm run build
```

Start production server:

```bash
npm run start
```
